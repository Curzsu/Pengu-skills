# Pengu-skills
如何制作生产级的 Skill ？需要考虑很多问题，我个人认为最需要考虑的问题有三点：

1. 如何去编写一个鲁棒性强的skill
2. 如何持续地去迭代skill
3. 如何构建适配于特定业务的skill评测体系



比如，如何找出 bad case？如何维护 bad case？什么样的 bad case 值得去维护？如何基于 bad case 去迭代 Skill？解决 bad case 后，如何保证 Skill 原有的功能不受影响？如何做更好的回归测试？如何节约测试成本（时间也算成本）？门禁需要设置些什么？如何保证跨平台兼容？如何去评估 Skill 的质量？等等等
